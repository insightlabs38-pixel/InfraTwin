# Final Demo Clip Review

The demo workflow proves capture reproducibility and media validity. It does **not** replace a human watch-through before final editing. Review every generated MP4 at normal playback speed and at full-screen 1080p.

## 01 Opening

- [ ] InfraTwin and Continental Service Network are immediately identifiable.
- [ ] Topology is visible immediately.
- [ ] ChangePlan and compact Inspector are readable.
- [ ] Network scale is credible without dominating the frame.
- [ ] Cursor motion and zoom are deliberate.
- [ ] No giant scrollbar, debug UI, loading flash, or empty pre-roll.

## 02 Collaboration

- [ ] Human selection and outage action are visually clear.
- [ ] Human-authored plan entry is readable.
- [ ] Native WebMCP reads the current selection.
- [ ] Agent-authored Payments growth appears in the same ChangePlan.
- [ ] Agent attribution/collaboration indicator is visible.
- [ ] No test harness, raw JSON, or fake agent/chat UI is shown.

## 03 Evidence

- [ ] Deterministic FAIL state is visible long enough to read.
- [ ] The distant Southeast–Central violation is clearly focused.
- [ ] The highlighted corridor and Inspector evidence agree.
- [ ] Numeric utilization/evidence is readable.
- [ ] No solver-debug detail distracts from the result.

## 04 Replan

- [ ] Initial cheapest proposal is visible before the override.
- [ ] Human lock/protection action is visually clear.
- [ ] Previous proposal visibly becomes stale.
- [ ] Re-analysis/replan does not look artificially instantaneous.
- [ ] Adaptive alternative is visible and verified.
- [ ] Locked modification target is not reused by the current proposal.
- [ ] Cursor never obscures the proposal or verification state.

## 05 Verify

- [ ] Plans view makes the alternative set understandable at a glance.
- [ ] Cost, peak/headroom context, and verification are readable.
- [ ] Human variant selection is visually clear.
- [ ] Final deterministic verification is visible.
- [ ] The clip communicates review + approval + verification rather than “agent gave an answer.”

## 06 Scale

- [ ] 500-node / 1,200-link / 400-demand scale is visually credible.
- [ ] Canvas rendering is responsive during the shown interaction.
- [ ] Search/focus is readable.
- [ ] No claim suggests Tier C adaptive design is interactive.
- [ ] Any numbers shown come from the deterministic scale fixture/current product surface.

## 07 WebMCP

- [ ] Advanced WebMCP diagnostics are concise and readable.
- [ ] Registered semantic tools are visible.
- [ ] A successful native activity event is visible.
- [ ] No fake ChatGPT/OpenAI/browser-agent UI is present.
- [ ] The shot is short enough to function as technical B-roll.

## Cross-clip review

- [ ] No blank page, page-load flash, setup operation, irrelevant wait, stale spinner, or accidental tooltip is present.
- [ ] Important text is readable at 1080p and after ordinary video compression.
- [ ] Menus do not cover important topology or evidence.

- [ ] The seven generated clips form a coherent human + agent story.
- [ ] Combined generated duration leaves adequate room under three minutes for framing, narration, transitions, and conclusion.
